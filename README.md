# 🎙️ AI-Транскрибатор видео

Сервис для фоновой транскрибации (распознавания речи) видео- и аудиофайлов. Проект демонстрирует работу с очередями задач и локальными AI-моделями, что позволяет обрабатывать тяжелые файлы без блокировки веб-сервера и без затрат на платные API.

## 🚀 Основные возможности

*   **Фоновая обработка задач:** Тяжелые задачи по распознаванию речи выполняются отдельным воркером (Celery), не блокируя основной веб-сервер (FastAPI). Пользователь может загрузить файл и сразу получить `task_id` для отслеживания статуса.
*   **Локальная нейросеть:** Используется модель `faster-whisper`, которая работает на процессоре вашего компьютера (CPU). Это полностью бесплатное решение, не требующее ключей OpenAI или других платных сервисов.
*   **Удобный веб-интерфейс:** Простая HTML-страница позволяет загружать файлы, следить за их статусом (PENDING/SUCCESS) и скачивать готовый текст в формате `.txt`.

## 🛠 Стек технологий

*   **Backend:** Python, FastAPI.
*   **Очередь задач:** Celery.
*   **Брокер сообщений:** Redis (облачный Upstash).
*   **AI-модель:** faster-whisper (локально).
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript.

## ⚙️ Как запустить локально

**Требования:** Установленный Python 3.10+ и доступ к базе Redis (например, бесплатный облачный Upstash).

    ```bash
    git clone https://github.com/olgatazkorob7-png/ai-video-transcriber.git

    Установите зависимости:

bash
pip install -r requirements.txt
Настройте переменные окружения:
Создайте файл .env в корне проекта и добавьте ссылку на вашу базу Redis:

env
REDIS_URL=redis://default:ваш_пароль@ваш_хост.upstash.io:6379
Запустите приложение (в двух терминалах):
Проект состоит из двух частей, которые должны работать одновременно.

Терминал 1 (Веб-сервер):

bash
uvicorn app.main:app --reload
Терминал 2 (Celery Worker):
python -m celery -A app.tasks worker --loglevel=info --pool=solo
(Флаг --pool=solo обязателен для работы Celery в Windows).
Откройте приложение:
Перейдите в браузере по адресу: http://localhost:8000
